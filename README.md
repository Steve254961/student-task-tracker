# Student Task Tracker

A React-based student task management application for organizing assignments, projects, and study activities.

## Features

- Student dashboard
- Task statistics
- Add new tasks
- Complete and undo tasks
- Delete tasks
- Select tasks
- Search tasks
- Category filtering
- Clear completed tasks
- Accessible task controls
- Empty-state feedback
- Automated regression tests

## Development

Install dependencies:

npm install

Run the development server:

npm run dev

Run tests:

npm test

Create production build:

npm run build
